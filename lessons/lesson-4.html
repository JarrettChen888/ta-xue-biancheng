第 4 课 · 约 25 分钟

让电脑学会判断

这一课只学一件事：让电脑看一个条件，自己选一条路走。

  • 难度：零基础
  • 需要准备：一台能上网的电脑，和一点点好奇
  • 可以随时停下，进度会自动记住

学完这一课，你会

  • 能让电脑根据一个条件，从两条路里选一条走
  • 能说清 === 和 = 各是做什么的
  • 写出一个“今天要不要带伞”的判断，并且跑起来

早上七点，你的手搭在门把手上，又收了回来，抬头看了看窗外。

天灰得像一块洗旧了的抹布。你没查天气预报，也没多想，转身回屋，把伞放进了包里。

这个动作只用了几秒钟：你先看一件事，再决定怎么做。天色阴沉，就带伞；太阳明晃晃，就空手走。你从来没有在心里列过表格，也没犹豫过第三种可能。

今天要让电脑学会的，就是这个动作。它不会看天，但它能听懂你给它的一句话：如果这句话是对的，走这条路；不对，走另一条路。

这件事有个名字，叫判断。你其实早就会了，只是今天要把它说给电脑听。

1

条件，是一句能回答“是”或“不是”的话

路口的红绿灯只有一个规矩：绿的，走；不是绿的，就停。灯的颜色就是条件。

电脑也只认两个答案：真和假，就是“是”和“不是”。你给它一句能回答“是或不是”的话，它才敢往下走。

所以你会怎么做：在 if 后面的圆括号里，写一句能回答“是或不是”的话。

例子：if (温度 >= 30) 的意思是——如果今天的温度大于或者等于 30 度。这句话要么对，要么不对，不会含糊。
2

三条横线 === 是比较，一条横线 = 是放下

把一条横线想成贴标签：你把一个值写下来，贴上名字，收进盒子。let 温度 = 32; 就是“这个盒子里放 32”。

三条横线是问一句：“这俩一样吗？”它只回答真或者假，不改动任何东西。

所以你会怎么做：起名字、放值的时候用一条横线；在 if 的圆括号里比较的时候，用三条。这个地方写错，电脑不会喊，它只会安静地做另一件事，要多留个心眼。

例子：let 温度 = 32; 是放下；if (温度 === 32) 是比较。把这两行的横线数数看。
3

else 是另一条路，两条路只走一条

带伞或者不带伞，你不会两样都做。if 和 else 也是这样：条件是真的，走 if 那一段；条件不是真的，才轮到 else。

永远只有一段会执行，另一段就像没写过一样。

所以你会怎么做：把“条件成立时做什么”写在 if 后面的花括号里，把“其余情况做什么”写在 else 后面的花括号里。

例子：温度是 32 度时，走的是 if 那一段，打印“开空调。”；把温度改成 25，走的就是 else 那一段，打印“开窗，让风进来。”——下面的动手区可以亲手试。
改完一定要点 ▶ 运行看看，代码不会自己动。想确认判断真的在起作用，把 32 改成 25 再运行一次：结果换成了另一句，就说明它真的在选。
如果点了运行，结果里跳出“出错啦：Unexpected token”这样的话，先看两处：if 后面的圆括号有没有写全，花括号是不是一左一右成对。还有，else 必须紧跟在 if 那一段的右花括号后面，中间不能插别的东西。少一个括号，电脑就整段都读不懂了。
