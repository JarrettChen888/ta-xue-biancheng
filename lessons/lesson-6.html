第 6 课 · 约 25 分钟

把本事打包：函数

这一课只学一件事：把好几行步骤打包成一句，喊名字就能用。

  • 难度：零基础
  • 需要准备：一台能上网的电脑，和一点点好奇
  • 可以随时停下，进度会自动记住

学完这一课，你会

  • 能把几行步骤写成一个函数，并给它起名字
  • 能说清“定义”和“调用”的区别
  • 能写出一个会打招呼、还能换名字的函数，并跑起来

家里来客人那天，你在厨房教家人做你那道凉拌黄瓜：拍碎、撒盐、挤汁、浇一勺热油。

说了三遍，还是漏掉一步。你索性撕下一张便签，把这四步写上去，用磁铁压在冰箱门上。

从那以后简单了：只要说一句“照冰箱上那张来”，这道菜就复现了。你不用每次都从头讲一遍，来帮忙的人也不用记。

今天要学的函数，就是这张便签。你把几行代码写进一个名字里，存起来；以后喊那个名字，电脑就把这几行从头到尾做一遍。

它省下的不是打字的时间，是“每一次都要重新交代清楚”的那种累。

1

定义：给一整套本事起个名字

function 这个词后面的第一件事，就是名字。你自己起，中文也行。function 打招呼() 的意思是：我有一套做法，名字叫“打招呼”。

花括号里写的，就是那套做法。写完之后，电脑只是把它收好了，还没有动手。

所以你会怎么做：先写 function 名字()，再把步骤放进花括号里。这一步叫定义。

例子：只写了 function 打招呼() { ... }，页面上什么都不会多出来。它像一张写好、贴上去、但还没人照着做的便签。
2

调用：写名字加一对圆括号，它才动

定义完，还得有人喊一声。打招呼(); 这一行的意思是：照那张便签，现在做一遍。

这两个动作很不一样：定义是“写下来”，调用是“现在做”。定义一次就够，调用可以很多次。

所以你会怎么做：先定义，再调用。少了后面这一步，页面上会安安静静，什么都没有。

例子：动手区里写了两行调用，就打印两行问候；写十行，就打印十行。函数只定义了一次。
3

参数与 return：能收东西，也能把结果交回来

函数名字后面那对圆括号，可以装东西。function 打招呼(名字) 里的“名字”，就是参数——调用的时候，你交给它用的东西。

做完之后，它还可以交回一个结果，靠的是 return。return 后面写什么，函数就把什么交出来。

所以你会怎么做：把要交给它用的东西写在圆括号里，把做完的结果写在 return 后面；然后拿外面那行 console.log 接住它。

例子：调用 打招呼("小林")，“小林”就是这次交进去的名字；函数把它拼成“你好，小林。”，用 return 交回来，console.log 才打印得出来。
如果点了运行，输出框里一个字都没有，先别怀疑自己。看看有没有写调用的那一行。光把函数写出来（function 名字() { ... }），电脑只是“知道了”，不会自己开始做。这不是你没学会，是还差一句“现在开始”。
起名字要一眼看得懂，中文也行；但定义和调用必须一字不差。差一个字，电脑就当那是另一个东西，安安静静什么都不做。

      如果结果里出现了一行 undefined，意思是“没有拿回东西”。最常见的原因，是函数里忘了写 return，或者把要交出去的结果直接在函数里 console.log 掉了——那样它只在函数里面说了一句，外面什么也没接到。回头看一眼：函数最后是不是有一行以 return 开头。要是 return 拼错了，比如写成 retrun，结果里会出现一句“出错啦”，改回来就好。
