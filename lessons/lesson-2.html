第 2 课 · 约 20 分钟

给网页换个样子

只学一件事：用几行样式，换颜色、换字号、换位置。

  • 难度：零基础
  • 需要准备：一台能上网的电脑，和一点点好奇
  • 可以随时停下，进度会自动记住

学完这一课，你会

  • 知道 CSS 只管样子，不管网页上写了哪些字
  • 会照样子写一行 选择器 { 属性: 值; }
  • 把背景换成暖色、标题换颜色、正文放到中间

快过年的时候，你把餐桌上的旧桌布收起来，换上一块暖红色的布，再摆两个橘色的靠垫。那天坐下来吃饭，家人都说屋里亮堂了。

桌子还是那张桌子，菜还是那几道菜，可一屋子看着就热闹了。你没买一件新家具，只是换了颜色。

网页也是这样。字还是那些字，句子还是那几句；换一换颜色、字号、位置，整页的感觉就不一样了。

做这件事的语言叫 CSS。今天只学几件小事：换背景、换颜色、改字号、把字放中间。

1

样子单独写在一对 style 标签里

网页的内容和样子是分开写的。文字还写在上一课那些标签里，样子单独写在一对 <style> 和 </style> 之间。

为什么不直接写在字旁边？因为想换样子的时候，只改这一块就够了，字一个都不用动。

例子：颜色、字号全写在 style 里，下面的 h1 和 p 还是原来那几行字，一个字都没改。
2

一行样式，像填一张小表

每一行样式都是三样东西排好队：先叫谁的名字，再写要改哪一项，最后写改成什么。

写法是 选择器 { 属性: 值; }。选择器是叫名字——h1 是大标题，p 是段落，body 是整页。冒号分开属性和值，分号表示这一行说完了。

常用的属性有三个：color 管字色，background 管背景，font-size 管字号，字号要写成 32px 这样。颜色可以直接写英文名，比如 black、darkred、orange、linen。

例子：p { color: dimgray; } 的意思是：所有段落，字改成暗灰色。
3

想让字居中，用 text-align

把字放到中间，用的属性叫 text-align，值写 center。

它管的是“这一块里的字怎么摆”。想让标题居中，就写进 h1 里；想让正文居中，就写进 p 里。

例子：h1 { text-align: center; }，标题就跑到中间去了。
一次只改一个值，运行一次。先改颜色，再改字号；哪一行起了作用，你一眼就看得出来。一起改三处，反而不知道是哪一行起的作用。

✍️ 动手区：把颜色换成你喜欢的暖色

运行结果


      

      

    


    

      如果你写了 text-align: center;，页面却一点没变，别急着怪自己。先看三处：冒号是不是打成了中文的“：”，分号是不是打成了中文的“；”，或者 center 拼成了 centre。电脑只认英文符号，也只认拼对的词；写错了它不吭声，只是把那一行跳过。颜色词也一样，darkred 少一个字母，这一行就白写了。

怎么打出英文的冒号、分号：先按一下 Shift 切到英文输入，再按冒号键和分号键；如果打出来还是“：”或“；”，说明输入法还在中文状态，再按一次 Shift。
