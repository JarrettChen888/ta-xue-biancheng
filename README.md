# 她学编程 · 慢慢来，学得会

写给 **50 岁左右、从零开始的女性**的中文编程入门课。纯静态网站：不需要注册、不收集任何信息、没有广告，学习记录只保存在你自己的浏览器里。

**在线访问**：<https://jarrettchen888.github.io/ta-xue-biancheng/>

---

## 这门课教什么

七节小课，每课只讲一件事，学完就停。从「代码是什么」一直走到「做出自己的网页」：

| 课 | 主题 | 学到的东西 |
| --- | --- | --- |
| 第 0 课 | 代码，其实就是一份说明书 | 代码是什么、网页由什么组成 |
| 第 1 课 | 让网页上出现你的字 | HTML 标签、标题与段落 |
| 第 2 课 | 给网页换个样子 | CSS 颜色、字号、居中 |
| 第 3 课 | 给信息取个名字：变量 | JavaScript 变量、console.log |
| 第 4 课 | 让电脑学会判断 | if / else、比较 |
| 第 5 课 | 重复的事，交给循环 | for 循环 |
| 第 6 课 | 把本事打包：函数 | function、参数、返回值 |
| 结业作品 | 我家的餐桌 | 做一张自己的家常菜单网页 |

每课的结构固定：生活故事 → 知识卡 → 可运行的动手区 → 小任务 → 三道小测验 → 三句话回顾 → 完成打卡。首页用「花瓣」记录进度，每学完一课开一片。

## 为谁设计

- 第一次接触编程、担心「我学不会」的人；
- 用手机、电脑只会看和点，不太敢乱动的人；
- 需要把字调大、需要朗读、需要深色背景的人。

## 无障碍（WCAG 2.2 AA 以上）

- 正文默认 20px，可调到 25px；宽行距、高对比度；浅色/深色两套配色均通过 axe 扫描；
- 每课故事可一键中文朗读，Esc 停止；
- 全站键盘可达，焦点 3px 蓝环；页面顶部有「跳到正文」；
- 可一键减少动画，并尊重系统「减少动态效果」设置；
- 语义化标签、ARIA 标注、图片替代文字；答对答错同时用符号与文字表达，不只靠颜色；
- 没有倒计时、没有自动播放、没有排行榜；
- JS 动手区会把英文报错翻译成人话（例如提示"引号是不是打成中文的了"），语法错误也不会让结果区一片空白；
- 每课的朗读覆盖「学习目标 + 开场故事」「知识卡」「小任务」「三句话回顾」；
- 练习区会自动把改动存在本机浏览器里，误刷新也能找回；
- 第一次要自己敲 `<` `>` `/` 时，课程里会先教怎么切英文输入法。

## 本地运行

不需要安装任何依赖，起一个静态服务器即可：

```bash
cd 项目/her-code
python3 -m http.server 8765
# 打开 http://127.0.0.1:8765/
```

也可以直接双击 `index.html` 打开（动手区的 iframe 在 `file://` 下同样可用）。

## 技术说明

- 纯 HTML + CSS + JavaScript，无框架、无构建步骤、无第三方依赖、无外部字体/CDN；
- 代码运行区把用户代码放进 `sandbox="allow-scripts"` 的 iframe 里执行，与主页面隔离；
- 学习进度与阅读设置存在 `localStorage`，不上传任何数据；
- 部署在 GitHub Pages（仓库设置 → Pages → Deploy from a branch → `main` / `/`）。

## 质量检查

上线前做过两轮检查：

1. **自动检查**：`python3 tools/check_site.py` + 真实 Chrome 逐页验收（链接、axe 无障碍扫描、测验交互、动手区执行、手机视图、进度闭环）。
2. **独立审计**：`AUDIT.md` 记录了上线前独立审计的发现与修复（P0 输入法说明、P1 结果框高度/存盘编码/朗读覆盖/地屏关联等）。

```bash
python3 tools/check_site.py
```

检查：占位符残留、内部链接、重复 id、三题测验的正确答案数、课号一致性、中文正文字数、禁用词、未定义样式类名。
