帮助、无障碍与常见问题

这个页面回答三类问题：怎么看得更舒服、你的学习记录在哪里、以及那些“我是不是不适合学”的担心。

无障碍说明

这个网站是照着“尽量让每个人都能用”的标准做的。下面这些，已经做到了：

  • 字号：正文默认 20 像素，比大多数网站大；可以再放大到 25 像素，所有文字和按钮会一起变大，不会挤坏版式。
  • 对比度：浅色和深色两套配色都达到 WCAG 2.2 AA 级以上的文字对比度，正文尽量接近 AAA 级。
  • 朗读：课程页有“🔊 读一读目标与开场”“🔊 读一读这三句话”，知识卡和小任务也能单独读。用的是浏览器自带的中文语音，按 Esc 随时停止。
  • 键盘操作：所有按钮和链接都能用 Tab 键到达，Enter 或空格确认；页面顶部第一个可聚焦元素是“跳到正文”。
  • 焦点可见：用键盘移动时，当前元素有 3 像素的蓝色描边，不会跟丢。
  • 减少动画：页面右上角可一键减少动画；如果你的系统设置了“减少动态效果”，网站会自动尊重这个设置。
  • 深色模式：右上角 ☾ 按钮切换，适合晚上或对强光敏感的人。
  • 结构清晰：标题层级、地标区域、表单标签、按钮状态都对屏幕阅读器友好；装饰性图案对读屏隐藏。
  • 不依赖颜色：答对答错除了颜色，还会用 ✓ / × 和文字说明表示。
  • 没有时限：没有倒计时、没有自动播放，所有内容都由你点击才开始。

如果你需要更多帮助

  • 字体调到最大还是看不清：可以用浏览器的“页面缩放”（Ctrl 或 ⌘ 加上 + 号）。
  • 朗读没有声音：先检查系统音量和浏览器是否被静音；Safari 和 Chrome 对中文语音的支持最好。
  • 用屏幕阅读器：页面使用语义化标签和 ARIA 标注，建议从“跳到正文”开始。
我们知道自己还做不到完美。如果你遇到用不了的地方，请把具体是哪一页、哪个操作告诉带你来的家人或朋友，让他们转达。这个站没有后台，不会自动收集你的任何信息。

阅读设置怎么用

页面右上角有一组按钮，在任何页面都能用。你的选择会保存在这台电脑上。

A− 缩小字号 A＋ 放大字号 ☾ / ☀ 切换深浅色 ✳ 减少 / 恢复动画
  • 连着点 A＋，字号会一档档变大（18 → 20 → 22 → 25 像素），到最大就停住。
  • ☾ 按钮第一次点会换成深色背景，再点一次换回米色背景。按钮上的符号也会跟着变。
  • ✳ 按钮会减少页面里的过渡和动画。如果你不点，网站会跟随你电脑系统的“减少动态效果”设置。

学习进度存在哪里

你的学习进度保存在这台电脑的浏览器里（技术上叫 localStorage）。所以：

  • 不需要注册、不需要登录，我们也看不到你学到了哪里。
  • 关掉页面、关掉电脑，下次打开还在。
  • 换电脑、换浏览器、用无痕模式，或者清除了浏览数据，进度就会消失——不是 bug，是隐私设计。
  • 想重来一遍，可以在浏览器设置里清除这个网站的数据，或者直接做练习：进度不影响任何内容的学习。

常见问题

我完全不懂英文，能学吗？

能。整个网站是中文的，代码里需要认识的英文单词只有十几个，每一课出现时都会解释。你不需要背单词，看多了自然就认识了。

我 50 多岁了，学这个是不是太晚？

不晚。这门课就是为这个年龄写的：每课只讲一件事，讲完立刻动手，不赶进度。学编程靠的不是记性快，是耐心和把事情说清楚的能力——这两样你有。

需要买新电脑或者装软件吗？

都不需要。能打开浏览器的电脑就行，练习直接在网页里完成，不用安装任何东西。

手机或平板能学吗？

能看课、能听朗读，也能在练习框里改代码；但打字、看运行结果还是电脑屏幕更舒服。条件允许的话，练习用电脑。

点了“运行看看”，结果没变化怎么办？

先看运行结果框里有没有以 ❌ 开头的提示；如果只是显示“已经运行了”，可能是改的内容不影响显示（比如改的是注释）。也可以点“恢复原样”，再从最小的一处改起。你在练习区的改动会自动存在这台电脑的浏览器里，刷新或关掉再回来还在（点“恢复原样”会清掉草稿），也不会影响你的学习进度。

改坏了代码怎么办？

点“恢复原样”，练习区就回到我给你的初始代码。改代码永远不会弄坏电脑，也不会影响别人。

朗读没有声音？

先确认系统音量和浏览器标签页没有静音；有些浏览器第一次使用语音需要等一两秒。Safari 和 Chrome 通常最稳。实在不行，用键盘也不影响学习。

这个网站收费吗？会收集我的信息吗？

不收费，没有广告，也不需要注册。网站没有后台服务器，不会收集你的姓名、电话或学习数据。唯一的“记录”是保存在你自己浏览器里的阅读设置和学习进度。

七课学完，接下来学什么？

先休息一下，把结业作品改到自己满意。之后如果想继续，可以试试 Python（更适合处理文件和数据），或者继续深入网页（给页面加交互）。到时候你会发现自己看教程的速度不一样了。

我可以把这个网站发给别人吗？

欢迎。这就是它存在的意义：让更多 50 岁左右的人发现，学编程不是年轻人的专利。
