# 课程内容写作指南（作者必读）

你写的是 **一个真实的人要跟着学会的东西**，不是 SEO 文章。
读者画像：50 岁左右的中文女性，退休或半退休，会用微信和手机拍照，第一次碰"编程"。
她的心理状态：好奇，也有点怕"我学不会""这是年轻人的东西"。

## 一句话标准

> 她读完这一课，**真的动过手、并且做成了一件小事**，而且期待下一课。做不到，就是没写完。

## 语音与文风（最重要）

1. **称呼**：一律用"你"，不要"您"（距离感）也不要"小姐姐""阿姨""姐妹们"（不尊重/刻板）。
2. **句子短**：一句不超过 25 个字；一段 2-3 句；段与段之间空行（Markdown 里就是多一个 `<p>`）。
3. **不哄小孩**：不要"哇塞！""超级简单哦~""小可爱"。要像一个懂行的朋友，平静、笃定、有分寸。
4. **先讲人话，再给术语**：先解释"标签就是给文字套的外套"，再顺口说"这个东西叫 HTML"。
5. **具体胜过形容词**：不写"非常有趣"，写"你改一个字，页面上的字马上跟着变"。
6. **允许她慢**：反复出现"可以停一下""不用记，用到再看""慢一点没关系"。
7. **不制造焦虑**：不提"别人都会""AI 要取代你""35 岁危机"。不卖课、不导流。
8. **性别中立**：不要默认她是妈妈/妻子/奶奶；可以写"家人"，不要写"老公孩子嫌你笨"这种桥段。
9. **比喻要生活化**：菜谱、收纳盒、红绿灯、洗衣机、遥控器、说明书、便签纸。每个比喻只用一次。
10. **每课只教一个新东西**。想多塞内容时，删掉。

禁止出现的词句：`赋能`、`底层逻辑`、`一键上手`、`小白必看`、`保姆级`、`轻松学会`、`干货满满`、`程序员`（改说"写代码的人"）、`前端/后端`。

## 每课固定结构（顺序不能变）

1. **课程头部**：标题、导语（一句话说清只学哪件事）、学习目标（3 条，动词开头，例如"能让网页显示一行大标题"）。
2. **生活故事** 150-250 字：先写一个具体生活画面，再落到今天要学的东西。
3. **知识卡 2-3 张**：一张只讲一个点，含生活比喻 + "所以你会怎么做" + 一个例子。
4. **提示卡**（`tip` 或 `note`，最多一个）：一条能救命的实操提醒。
5. **动手区**：代码必须能跑，初始代码就是"可用的半成品"，让她只改一点点。动手区上方标题要写清"改成你自己的什么"。
6. **小任务**：5 分钟内能做完，3 个步骤 + 2 条自查。
7. **三道测验**：每题一正两错（或一正一错），错误选项要像"初学者真的会犯的错"（例如 `=` 和 `===` 混用），答错反馈只给提示，不直接报答案。
8. **三句话回顾**：三个要点，能直接背下来。
9. **底部导航**：上一课 / 我学完这一课了 / 下一课。

## 技术要求

- 只写你负责的 `lesson-N.html`。**不要改** `assets/`、不要改其他人的页面、不要新建 CSS 或 JS。
- 直接用 `lessons/_template.html` 里的结构与类名；固定区块（页头/页脚/脚本引用的顺序与属性）保持原样。
- 正文里出现代码，用 `<code>&lt;h1&gt;</code>` 这种转义形式；**代码块**用：
  ```html
  <pre><code>&lt;h1&gt;我的标题&lt;/h1&gt;</code></pre>
  ```
- 动手区 `<textarea>` 里可以直接写未转义的 HTML 标签（textarea 是纯文本容器），但**绝不能出现字符串 `</textarea>`**。
- JavaScript 只用最朴素的写法：`let`、`const`、`if/else`、`for`、`function`、`console.log`、字符串相加 `+`。
  不用箭头函数、模板字符串、`map/filter`、`document.querySelector`（第 0-6 课不需要操作 DOM）。
- JS 动手区用 `data-playground="js"`，代码里用 `console.log(...)` 输出，页面会自动把输出显示在深色框里。
- 所有中文标点用全角；代码与英文保持半角。数字与英文两侧各留一个空格（例如 "50 岁"、"HTML 文件"）。
- 每页唯一 id 不要重复；`data-speak="lesson-intro"` 的朗读按钮保留（它读的是故事区）。
- 页面标题格式：`第 N 课 · 标题｜她学编程`；`<meta name="description">` 写 30-60 字。
- `body` 上的 `data-lesson="N"`、完成按钮上的 `data-complete="N"` 必须是真实课号。

## 进阶写法：让"卡住的人"不放弃

每课至少有一处 **"如果你看到的是……那不是你笨"** 的具体说明（用 `<aside class="mistake">`），例如：

> 如果你看到页面上出现 `&lt;h1&gt;` 这几个字本身，而不是一个大标题，通常是因为结尾少了一个 `&gt;`，或者把 `h1` 写成了 `hl`（字母 l 和数字 1 长得像）。

## 参考范文

`lessons/lesson-0.html` 是标准范文（语音、结构、代码区、测验的写法都以它为准）。先完整读一遍，再动笔。
